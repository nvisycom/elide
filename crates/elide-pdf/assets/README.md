# Shipped assets

`elide-pdf` compiles the files under this directory into the binary with `include_str!`.

## `afm/`

Adobe's Core14 AFM files: the font metrics of the 14 standard fonts (ISO 32000-2, 9.6.2.2), which a PDF may name without embedding or giving `/Widths` for. `src/pdf/reader/font/standard/mod.rs` reads each glyph's name, code and advance width from them.

The 14 `.afm` files and `MustRead.html`, which carries Adobe's licence for them, are unmodified from Adobe's `Core14_AFMs.zip`; `.gitattributes` keeps their original line endings. `scripts/pdf/fetch-afm.sh` fetches them again, checking the archive against a pinned SHA-256.

The WinAnsi, MacRoman, Mac OS Roman and MacExpert glyph-name tables in `src/pdf/reader/font/standard/encodings.rs` are generated by `scripts/pdf/gen-encodings.mjs`.

## `agl/`

The Adobe Glyph List (`glyphlist.txt`) and its ZapfDingbats list (`zapfdingbats.txt`): the text each glyph name stands for. `src/pdf/reader/font/standard/glyph_list.rs` reads them to decode a standard font's text from the glyphs its encoding selects.

Both files and `LICENSE.md`, their BSD-3-Clause licence, are unmodified from `adobe-type-tools/agl-aglfn`. `scripts/pdf/fetch-agl.sh` fetches them again at a pinned commit, checking each against a pinned SHA-256.
